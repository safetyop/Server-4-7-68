ประเภทของเครื่องแม่ข่ายในระบบเครือข่าย

1. Web Server (เว็บเซิร์ฟเวอร์)

หน้าที่หลัก: ให้บริการจัดการและส่งข้อมูลเว็บไซต์แก่ผู้ใช้งานผ่านโปรโตคอล HTTP หรือ HTTPS

ตัวอย่างซอฟต์แวร์: Apache HTTP Server, Nginx, Microsoft IIS

2. File Server (ไฟล์เซิร์ฟเวอร์)

หน้าที่หลัก: ให้บริการจัดเก็บไฟล์และแบ่งปันไฟล์แก่ผู้ใช้งานในเครือข่าย

ตัวอย่างซอฟต์แวร์: Samba, Windows Server File Services, TrueNAS

3. Authentication Server (เซิร์ฟเวอร์ตรวจสอบสิทธิ์)

หน้าที่หลัก: ตรวจสอบชื่อผู้ใช้และรหัสผ่านเพื่อควบคุมการเข้าถึงระบบและข้อมูล

ตัวอย่างซอฟต์แวร์: FreeRADIUS, Active Directory, OpenLDAP

4. Database Server (ฐานข้อมูลเซิร์ฟเวอร์)

หน้าที่หลัก: จัดการและให้บริการฐานข้อมูลสำหรับแอปพลิเคชันและเว็บไซต์ต่าง ๆ

ตัวอย่างซอฟต์แวร์: MySQL, PostgreSQL, Microsoft SQL Server, Oracle Database

5. Mail Server (เมลเซิร์ฟเวอร์)

หน้าที่หลัก: จัดการการส่งและรับอีเมลระหว่างผู้ใช้งานผ่านอินเทอร์เน็ต

ตัวอย่างซอฟต์แวร์: Microsoft Exchange, Postfix, Sendmail, Zimbra

6. DNS Server (เซิร์ฟเวอร์ระบบชื่อโดเมน)

หน้าที่หลัก: แปลงชื่อโดเมน (เช่น www.google.com) ให้เป็น IP Address เพื่อให้เครื่องสามารถเชื่อมต่อกันได้

ตัวอย่างซอฟต์แวร์: BIND, Microsoft DNS, PowerDNS, Unbound
